2. DATASET SPECIFICATIONS
   - Total Rows Rendered: 200,000 records
   - Total Fields: 39 columns (37 base columns + calculated fields)
   - Scope: Vehicle specs, sales, ratings, geography, sustainability.

3. CALCULATED FIELDS CREATED IN TABLEAU
   - Calculation1: Sales (Millions) -> [Annual Sales Units] / 1000000
   - Calculation2: High Efficiency Flag -> IF [Driving Range Km] > 320 AND [Battery Capacity Kwh] < 80 THEN True ELSE False END
   - Calculation3: Recommended Use Case -> Categorizes vehicles into Urban Commute, Family Daily Use, Highway Long-Distance, Executive.
   - Calculation4: Formatted Total Sales -> "$" + STR(ROUND(SUM([Annual Sales Units]) / 1000000, 1)) + "M Units"
   - Calculation5: Efficiency Ratio -> AVG([Driving Range Km]) / AVG([Battery Capacity Kwh])
